# Linux Animation Studio v0.41.0-rc.1

**Status:** Release candidate preparation. Not merged into `main`; no stable release published.

**Application name:** Linux Animation Studio (SpynFrame icon trial only). **Project files:** `.las` format 6, unchanged. **Version shown in window/About:** `0.41.0-rc.1`. **Package naming:** `LinuxAnimationStudio-0.41.0-rc.1-<platform>.*`.

## Highlights

- New Eyedropper tool (`I`) with toolbar pipette glyph and sampling from all visible artwork or only the active layer, respecting transparency.
- Automatic pen-flip Eraser on supported Wacom-style hardware, retaining pressure and restoring the previous tool; mouse/keyboard/manual Eraser remain available.
- Refined numeric sliders, defaults, independent tool settings, built-in brush pressure strength, and audio/waveform gain controls.
- Context menu dismissal reliably avoids unwanted brush/eraser marks or Paint Bucket fills and restores the correct cursor. Extra Linux/Wayland click suppression removed.
- Continued backward compatibility for existing projects and exports.

## Verification history

Pre-release-candidate revision: **189/189 automated tests on each OS** (567/567 executions). Eraser-end hardware checks were not applicable on macOS or Linux, but passed on the Cintiq.

## Native build and packaging

Run from the checked-out `feature/v0.41-interface-refinement` branch, inside the OS-specific virtual environment.

```sh
python -m unittest discover -s tests -q
python -m pip install -r requirements-build.txt
python tools/build.py --dry-run
python tools/build.py
python tools/check_build.py
python tools/package_release.py --dry-run
python tools/package_release.py
```

On macOS, use `python3` if that is the virtual environment command. Windows PowerShell can invoke `.\.venv\Scripts\python.exe` in place of `python`; on macOS/Linux, `source .venv/bin/activate` first. The build and package steps must run independently on each native OS.

### Expected artifacts

| OS | Target package | Additional requirements |
| --- | --- | --- |
| Windows | `releases/LinuxAnimationStudio-0.41.0-rc.1-windows-setup.exe` | Inno Setup 6 |
| macOS | `releases/LinuxAnimationStudio-0.41.0-rc.1-macos.dmg` | macOS `hdiutil` |
| Linux | `releases/LinuxAnimationStudio-0.41.0-rc.1-linux.tar.gz` | native Linux environment |

macOS DMGs are unsigned and unnotarized. After attempting the trusted download, use **System Settings → Privacy & Security → Open Anyway** if Gatekeeper blocks the app. Linux archive offers `run.sh`, `install.sh`, `uninstall.sh`. FFmpeg is not automatically bundled unless explicitly supplied (mind licensing).
